## API Integration with CKB

### Objectives
- Creating an API route written in Next.js for fetching token balances from the CKB testnet.
- Adding a frontend component for calling the API and displaying the result.

### What I learnt 
- The pattern for any CKB data query is always:
    - Convert address → lock script
    - Build the type/lock script you're searching for
    - Read and process cell data
    - Return results
- It works the same way for tokens, NFTs, messages, anything stored within cells.
- Reading token amounts
    - Token amounts are saved in little-endian format in 16 bytes: ccc.numLeFromBytes(cell.outputData) gets token amount as BigInt
- Why multiple cells can hold the same token
    - One address can have SEVERAL cells containing the same token. This happens after several transfers, and each transfer generates its cell. So, balance is the TOTAL of all of them.
