# Day 30 - 31: May 10th, 2026 - May 11th, 2026

## Setting up a working email/password authentication 

### What I Did
- I chose to use Better Auth and SQLite for the secondary login and sign-up section because of the easy setup and integration
- I integrated the Better Auth tool into my Next.js app
- Then I created and configured the auth server in the lib folder (lib/auth.ts)
- Added the Better Auth route handler in the api folder
- I went back and added the client auth helper to the lib folder 
- Then linked my login/signup UI to the auth actions
- I also made sure to make the profile route a protected route
- Then, I finally made the navbar session-aware and added a redirect behavior so it logs out when your session expires and redirects back to the login page

### Today's Task
- Setting up a secondary form of user authentication (email login/signup)

### What I Learned
- Better Auth requires appropriate environment variables, particularly BETTER_AUTH_SECRET and BETTER_AUTH_URL.
- Authentication involves more than mere frontend form wiring; it also entails route handling, schema design, and session handling.
- Schema creation for SQLite is an essential aspect, and table absence can lead to 500 authentication errors.
- Client components best handle UI elements such as tabs and drop-down menus.
- Sign-out functionality involves both backend logout and frontend redirection.
