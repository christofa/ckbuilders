# Day 32-33: May 12th, 2026 - May 13th, 2026 

## Setting Up Wallet Connect

### What I Did
- Installed @ckb-ccc/connector-react and @ckb-ccc/core
- Created the CKBProvider component file
- Wrapped the entire app in the layout file
- Added the functionalities in the auth API route that create users from wallet addresses
- Wired the connect CKB wallet button to the CKB wallet selector
- The connection supports JoyID, MetaMask, and other wallets

### The Wallet connection flow 
The User click on the "Connect CKB Wallet" -> the CKBProvider opens the wallect selection model -> User chooses a wallet ->The wallet connects and returns the CKB address -> the wallet address is then sent to the auth api -> server checks if the user exists with the address -> if yes, returns the user -> if no, asks user to create a new wallet -> then the session token is created and stored -> Finally, the user is redirected to the dashboard 

### What I Learned
- Wallet connection state is not the same thing as backend authentication state.
- If there are two ways to gain access within one app, the routing needs to consider this, or else endless loops will occur.
- CCC integration depends on wrapping the app in the correct provider and using the correct hooks from the installed package version.
