# Day 88-92: Aug 23rd - Aug 28th, 2026

## Implementing CKB Vote Cells in ContestLedger

### My Aim 
My target this week was to change ContestLedger's signature-based voting to real CKB transactions. So any vote made by users becomes a Vote Cell on CKB testnet and is permanently recorded, publicly auditable, and independently verifiable without the database. This is the final piece needed to make my project's entire data model trustless.

### What I Did
- Firstly, I removed the old voting layer because it used a challenge-sign verify pattern where the backend creates a unique message that the frontend then asks the wallet to sign while the backend verifies the signature. This ensured the person was the owner of the wallet but didn’t involve a transaction on CKB. 

- Built the Vote Cell Transaction, The new `handleVote()` function creates an actual CKB transaction, not a signature of a message. All information required for verification of the Vote Cell can be extracted directly from the chain data.

- Stored the Vote TX Hash: The votes table got a new `tx_Hash` column so every vote row in Turso carries a link to it on-chain proof.

### What I Learned
- CKB follows the same transaction flow when working with various types of Cell. Knowing how to construct a Vote Cell, I knew how to do it for other types such as Contest and Entry Cells, encode data, set capacity, create transaction, finalize it, and send it.
- SQLite is not very flexible when it comes to making changes in schema. I have found out that adding specific constraints to a table through `ALTER TABLE` is not as simple as it may seem. In this case, a simpler method would be better since the blockchain will handle uniqueness.
- One step builds on the other. Once the contests and entries were verified, voting verification became a lot easier thanks to the previously set up verifications.
- Error messages give you exactly what needs fixing. For instance, the votes table error was clear in pointing out the lack of tx_hash field. Once I started reading the message correctly, the fix was not too difficult to apply.
