# CKB Builders Learning Repository

This repository contains a development learning log and exercise notes for the CKB Builders program. It is organized by week and contains daily summaries, code exercises, and supporting screenshots.

## Repository Structure

- `Week1/` through `Week11/` — weekly progress notes and daily reflections.
- `exercises/` — practice files, coding challenges, or sample projects.
- `screenshots/` — visual reference images for completed work or classroom examples.

## How to Use This Repo

1. Open the relevant week folder to review notes from that part of the course.
2. Read daily markdown files for summaries, learnings, and task breakdowns.
3. Use the `exercises/` folder to find practice code and examples related to the lessons.
4. Refer to `screenshots/` for visual guides or result references.

## Purpose

The repository is intended to:

- Track learning progress during the CKB Builders program.
- Keep daily summaries and notes in an easy-to-review format.
- Store coding exercises and examples for later reference.
- Provide a structured archive of what was covered each week.

## Notes

- File names may include day ranges and lesson topics.
- Weekly folders are organized chronologically from Week 1 to Week 11.
- Additional notes, exercises, or supporting materials can be added as the program continues.
